# Vitta — Maquetado

Maquetado HTML/CSS/JS del prototipo de **Vitta**, la app de hábitos y
gamificación. Este archivo (`index.html`) es la fuente de verdad visual
usada para migrar el diseño al proyecto Android nativo
([Kotlin + Jetpack Compose](https://github.com/vXro1/Vitta)).

## Contenido

- `index.html` — el maquetado interactivo completo (una sola página).
- `assets/` — íconos, insignias e ilustraciones de la mascota usados por
  el maquetado, organizados por tipo.

## Cómo verlo

Abre `index.html` directamente en el navegador, o publícalo con GitHub
Pages (rama `main`, carpeta raíz).
